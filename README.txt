===========================================================
         לוח הקומה — הפעלה אוטומטית + שליטה מרחוק (AnyDesk)
===========================================================

מה זה עושה:
  • יוצר במחשב משתמש חדש בשם "לוח הקומה".
  • המחשב נכנס אליו לבד בכל הדלקה — בלי סיסמה ובלי נגיעה.
  • הלוח נפתח לבד במסך מלא (קיוסק), ו*נשאר* במסך מלא:
    אם Chrome ייסגר / יקרוס / יתעדכן — הוא ייפתח שוב לבד תוך שניות.
  • המסך לא נכבה ולא נכנס לשינה.
  • עם AnyDesk — תשלוט במחשב מהטלפון מכל מקום, תמיד, והלוח ממשיך להופיע על הטלוויזיה.


-----------------------------------------------------------
 חלק א' — התקנת הלוח (פעם אחת)
-----------------------------------------------------------
1. ודא ש-Google Chrome מותקן על המחשב (אם לא — התקן אותו).
2. פתח את ה-zip ו*חלץ את כל הקבצים* לאותה תיקייה (Extract All) —
   למשל לשולחן העבודה. חשוב: כל הקבצים באותה תיקייה.
3. קליק ימני על הקובץ:  install.bat
   בחר:  "Run as administrator" / "הפעל כמנהל".
4. יופיע חלון שחור עם 5 שלבים — חכה שיסיים וכתוב "הסתיים בהצלחה".
5. כבה והדלק את המחשב. הוא ייכנס לבד ללוח במסך מלא.

  * פרטי המשתמש שנוצר:  שם: luach   סיסמה: luach
  * הלוח יישאר במסך מלא תמיד. אם אי פעם ייצא — הוא ייפתח לבד.

  לתחזוקה (למשל דרך AnyDesk):
  * לעצור את הלוח:  לחיצה כפולה על "Stop-Board" בשולחן העבודה.
  * לפתוח שוב:      לחיצה כפולה על "Open-Board" בשולחן העבודה.


-----------------------------------------------------------
 חלק ב' — AnyDesk לשליטה מרחוק *תמידית* (בלי לחדש)
-----------------------------------------------------------
כדי שהשליטה תעבוד תמיד, גם כשאף אחד ליד הטלוויזיה, צריך 3 דברים:
התקנה כשירות + התחלה עם Windows + סיסמת גישה קבועה. כך זה *לא צריך חידוש*.

על המחשב של הלוח:
1. הורד את AnyDesk מ:  https://anydesk.com/he  (לחצן Download).
2. פתח את AnyDesk, ובתפריט בחר:
   "Install AnyDesk on this computer" / "התקן את AnyDesk על מחשב זה"
   ואשר. (זה מתקין אותו כשירות שמתחיל עם Windows — ולכן עובד תמיד.)
3. רשום לעצמך את המספר בן 9 הספרות (This Desk) — זה המזהה להתחברות.
4. Settings (הגדרות) -> Security (אבטחה) -> Unlock Security Settings:
   • סמן "Enable unattended access" / "אפשר גישה ללא השגחה"
   • קבע סיסמה חזקה משלך ושמור אותה.
   • סמן גם "Allow connection when the screen is locked" (אם מופיע).
5. Settings -> General: ודא ש-"Start AnyDesk with Windows" מסומן.

מהטלפון:
6. התקן את אפליקציית AnyDesk (iPhone/Android), הקלד את מספר ה-9 ספרות
   ואז את הסיסמה שקבעת — ותתחבר *בכל פעם, בלי לחדש*. תראה את הלוח
   ותוכל לנהל את המחשב. הלוח ממשיך להופיע על הטלוויזיה.

  הערה: AnyDesk חינמי הוא לשימוש פרטי. אם אי פעם יקפוץ חלון
  "שימוש מסחרי" שמגביל — אפשר לעבור ל-Chrome Remote Desktop (חינם לגמרי,
  בלי הגבלה) שעובד בדיוק באותו אופן. תגיד לי ואכין לך הוראות.
