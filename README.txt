===========================================================
         לוח הקומה — הפעלה אוטומטית + שליטה מרחוק (AnyDesk)
===========================================================

מה זה עושה:
  • יוצר במחשב משתמש חדש בשם "לוח הקומה".
  • המחשב נכנס אליו לבד בכל הדלקה — בלי סיסמה ובלי נגיעה.
  • הלוח נפתח לבד במסך מלא (קיוסק) מהקישור הקבוע.
  • המסך לא נכבה ולא נכנס לשינה.
  • עם AnyDesk — תשלוט במחשב מהטלפון מכל מקום, והלוח ממשיך להופיע על הטלוויזיה.


-----------------------------------------------------------
 חלק א' — התקנת הלוח (פעם אחת)
-----------------------------------------------------------
1. ודא ש-Google Chrome מותקן על המחשב (אם לא — התקן אותו).
2. חלץ את שני הקבצים (install.bat ו- board-kiosk.bat) לאותה תיקייה
   על המחשב של הלוח — למשל לשולחן העבודה.
3. קליק ימני על הקובץ:  install.bat
   בחר:  "Run as administrator" / "הפעל כמנהל".
4. יופיע חלון שחור עם 5 שלבים — חכה שיסיים וכתוב "הסתיים בהצלחה".
5. כבה והדלק את המחשב. הוא ייכנס לבד ללוח במסך מלא.

  * פרטי המשתמש שנוצר:  שם: luach   סיסמה: luach
  * ליציאה זמנית מהלוח (לתחזוקה):  Alt+F4
  * לפתיחה מחדש של הלוח:  לחיצה כפולה על "Open-Board" בשולחן העבודה.


-----------------------------------------------------------
 חלק ב' — AnyDesk לשליטה מרחוק מהטלפון
-----------------------------------------------------------
על המחשב של הלוח:
1. הורד את AnyDesk מ:  https://anydesk.com/he  (לחצן Download).
2. פתח את AnyDesk. רשום לעצמך את המספר בן 9 הספרות שמופיע תחת
   "כתובת שולחן העבודה שלך" (This Desk) — זה המזהה להתחברות.
3. התקן אותו קבוע:  בתפריט בחר "Install AnyDesk on this computer"
   וסמן שיופעל עם Windows (Start with Windows).
4. הגדר כניסה בלי אישור ידני (חשוב — כדי שתוכל להתחבר כשאף אחד לא ליד הטלוויזיה):
   Settings (הגדרות)  ->  Security (אבטחה)  ->  Unlock Security Settings
   ->  סמן "Enable unattended access" / "אפשר גישה ללא השגחה"
   ->  קבע סיסמה חזקה משלך ושמור אותה.

מהטלפון:
5. התקן את אפליקציית AnyDesk (iPhone/Android), הקלד את מספר ה-9 ספרות
   של המחשב, ואז את הסיסמה שקבעת — ותתחבר. תראה את הלוח, ותוכל לנהל
   את המחשב (לאתחל, לפתוח מחדש וכו'). הלוח ממשיך להופיע על הטלוויזיה.
