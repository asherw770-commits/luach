🖥️ התקנת לוח הקומה

הפעלה אוטומטית במסך מלא בכל הדלקה — בלי נגיעה
⬇️ הורדת קובץ ההתקנה luach-kiosk-setup.zip — שלושה קבצים

מה עושים אחרי ההורדה

  1. ודאו ש-Google Chrome מותקן על המחשב.
  2. פתחו את ה-zip וחלצו את כל הקבצים לאותה תיקייה (Extract All).
  3. קליק ימני על install.bat ← הפעל כמנהל (Run as administrator).
  4. חכו שיופיע "הסתיים בהצלחה", ואז כבו והדליקו את המחשב.
המחשב ייכנס לבד למשתמש luach ויפתח את הלוח במסך מלא — והלוח יישאר במסך מלא תמיד (אם ייסגר, ייפתח לבד).
לתחזוקה: Stop-Board לעצירה, Open-Board לפתיחה — קיצורים בשולחן העבודה.

שליטה מרחוק מהטלפון (AnyDesk)

  1. הורידו AnyDesk מ-anydesk.com/he והתקינו (Start with Windows).
  2. רשמו את מספר ה-9 ספרות שמוצג.
  3. Settings ← Security ← Unlock ← סמנו Unattended access וקבעו סיסמה.
  4. מהטלפון: אפליקציית AnyDesk ← מספר המחשב ← הסיסמה. הלוח ממשיך להופיע על הטלוויזיה.
לשינוי תוכן הלוח (הודעות/תמונות/זמנים) לא צריך AnyDesk — עושים מהטלפון בדף הניהול /#manage.

אם ההורדה למעלה נחסמה — הורדה בודדת

install.bat board-kiosk.bat run-hidden.vbs Open-Board.bat Stop-Board.bat README.txt
הורידו את שלושתם לאותה תיקייה, ואז הפעילו את install.bat כמנהל.
